# 🌍 Trip Planner

A full-stack AI-powered Trip Planner web application that helps users plan personalised trips based on their destination, budget, travel dates, and preferences. The application provides itinerary planning, destination recommendations, and an intuitive user experience with a modern responsive interface.

---

## 🚀 Features

* 🗺️ Create personalised travel itineraries
* 📍 Destination recommendations
* 💰 Budget-based trip planning
* 📅 Day-wise itinerary generation
* 🔐 User authentication and secure access
* 📱 Responsive UI for desktop and mobile
* ⚡ Fast and interactive user experience
* 🌐 REST API integration
* 🎨 Modern UI built with React and Tailwind CSS

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Divyan7/trip-planner.git
```

Move into the project directory

```bash
cd trip-planner
```

Install dependencies

```bash
npm install
```

---

## ▶️ Running the Project

Start the development server

```bash
npm run dev
```

The application will start on the configured local development ports.

---

## 🔧 Environment Variables

Create a `.env` file in the project root and configure the required environment variables.

Example:

```env
JWT_SECRET=your_secret_key
OPENAI_API_KEY=your_api_key
```

> Replace the above values with your own credentials.
